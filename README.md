## Getting started:

1.  Clone the repo to your IDE
2.  Create the .Venv (the virtual environment) either with the GUI or with this command: python -m venv venv
3.  Start the virtual enviroment by running this command: "**.venv\Scripts\Activate.ps1" or click on the Activate.ps1 file in your IDE and run it
4.  install the dependencies with this command: python -m pip install -e.
5. run the program with "Python ProgramSelector.py -h" for help with what launch options and how to run the program

the program can be run with -LC for live comparison, -ML "insert path here" for creating a csv dataset from filepath with alphabet. -IGE "insert file path" for running image gesture evaluation on images at the file path.
